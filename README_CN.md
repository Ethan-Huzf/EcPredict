# EcPredict 中文说明

本仓库为并五苯电子耦合机器学习论文配套的**纯代码版**，不包含数据、轨迹、预测记录、训练模型或Word稿件。

主说明和可直接使用的命令见英文 [README.md](README.md)。

## 内容

- `descriptors/`：从二聚体坐标生成DM；按实际七组权重生成OPT3D；合并多帧描述符。
- `models/`：8份实际拟合任务保存的训练源码，逐字节保留，并记录SHA-256及参考GPU型号。
- `run_experiment.py`：统一选择DM/OPT3D、V/|V|、随机/聚类、P和训练比例；额外导出原始训练/测试预测及复现信息。
- `quantum/`：已有的二聚体截取和PW91/6-31G*耦合重算工具，不附带拓扑或轨迹。
- `plotting/`：用运行后实际导出的预测绘制封闭坐标框散点图和学习曲线。
- `configs/`：原研究ANN参数，不虚构不存在的网格搜索或贝叶斯优化流程。
- `docs/`：数据格式、实际聚类算法、运行环境、文献和源码来源说明。

## 与论文对应

1–1297直接学习相位参考下的带符号V；Frame5及Merged Frames直接学习|V|。幅值任务的网络预测不再做取绝对值处理，也不截掉负预测值。图中训练点只统计原始构型，不把DM置换副本当作新增训练分子构型。

默认OPT3D为sl=0.1、nsc=100；nsc=32是另外的设置。权重顺序为U、M、V、P、E、IP、RC，与本研究转换程序一致，不能照搬参考仓库中九权重的总维数。

新仓库不改写原训练算法。统一入口只增加参数选择、结果导出和兼容处理。原始流程将后续称为Test的子集用于早停及学习率调整，文档已明确说明，不能把这些结果表述为完全独立外部测试。CPU/GPU分支、PCA求解器和硬件不同会影响结果；精确复现仍需要原始数据、划分和环境。

## 使用

从仓库根目录安装依赖后，运行：

```bash
python run_experiment.py --help
python -m unittest discover -s tests -v
```

正式GPU实验建议加`--require-gpu`；如指定硬件，再加`--expect-gpu 'RTX 4090'`。每个任务使用新输出目录，不复用其他数据集的缓存。

论文最终发表后补齐`CITATION.cff`的正式引用信息。公开前由作者确定代码许可证；不要因参考仓库采用MIT便自动沿用其版权归属。
